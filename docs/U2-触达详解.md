# U2 触达详解：「跟进」是怎么跑到你面前的

## 一、先厘清 U2 到底管什么

U2 只回答一件事：**系统主动出现在你面前的路径，长什么样。**

它管三件事：

1. 什么时候触发。
2. 通过什么通道送到你面前。
3. 你没回应时怎么办。

### 一个反直觉的点：事件触发其实不需要 U2

之前定的触发是「每周定时 + 交付物完成时事件触发」。但仔细想：**事件触发根本不需要推送。**

因为你完成交付物、提交报告的那一刻，你人就在系统里。系统当场就能回应你（「阶段 2 完成，要不要进阶段 3」）。这不叫触达，叫交互的返回值。

所以 U2 真正要解决的只有**一条路径**：每周那一次兜底 —— 在你没回来的时候，谁把你拉回来。

范围一下小了，这也是为什么它值得单独定：它是唯一一个「你不在场」的场景。

---

## 二、四个档位，逐个说细节

### 档 0 被动：不做推送

- **形态**：没有推送。你打开网页才看得到状态。
- **你需要做什么**：什么都不用做。
- **实际体验**：想不起来就不会看。两周后你连这个项目都忘了。
- **成本**：0。
- **结论**：等于放弃跟进这半。你明确说过跟进要做，所以排除。

### 档 1 本地通知

- **形态**：Windows 任务计划程序每周触发一次脚本，弹一条系统通知（或把一份 HTML 写到桌面）。
- **你需要做什么**：配置一条任务计划，约 15 分钟，一次性的。
- **实际体验**：只有你在电脑前的那几分钟能看到。Windows 通知默认几秒后收进通知中心，很容易被无视。
- **短板**：你是学生，白天基本不在电脑前。一条只在电脑前闪一下的提醒，约等于没有。
- **成本**：0 元。

### 档 2 本地定时 + 邮件

- **形态**：同一套任务计划程序，触发时把「三问摘要」用 SMTP 发到你邮箱，手机能收到。
- **你需要做什么**：一个邮箱的 SMTP 授权码（QQ / 163 免费，配一次）。代码侧要加一段**补发逻辑**：记录 `last_sent_at`，应用下次启动时若发现错过了上一次检查点，补发并标注「补发」。
- **实际体验**：每周固定时间手机上收到一封，内容就是三问。
- **一个必须提前知道的细节**：后端跑在本地，**手机点不开本地页面**（`127.0.0.1` 只在你自己电脑上有效；除非手机和电脑同一 WiFi 并用内网 IP，那又要处理 IP 变动）。所以：
  - **邮件只做提醒，不放操作链接**，正文末尾写「回电脑上打开页面更新」。
  - 提醒本身就是核心价值 —— 它把你从「忘了这件事」拉回到「我知道该回电脑上处理」。
- **补发逻辑为什么必须有**：任务计划程序只在电脑开机时才会跑。那个时间点电脑关着，这次就漏了。
- **成本**：0 元。

邮件长这样（样例）：

```
主题：cadence · 周检查点（阶段 2）

当前阶段：阶段 2 — 用 FastAPI 做出能读写的接口
          交付物：接口能读写，数据落 SQLite

本周推到哪：检查点 2「接上 SQLite 读写」仍为进行中，落后 3 天

建议怎么调：把检查点 2 拆成两步 —— 先只做只读，再加写入；
            或者把检查点 3 顺延一周

回电脑上打开 http://127.0.0.1:8000 更新
```

### 档 3 云端常驻

- **形态**：后端搬到云上，状态也在云；定时任务跑在云上（不依赖你的电脑开不开机）。
- **你需要做什么**：FastAPI 部署到 Render / Fly 免费层（会休眠，冷启动慢）；数据库从 SQLite 换托管 Postgres（Neon / Supabase 免费层）；配环境变量、密钥、跨域。
- **实际体验**：最完整的「主动」——任何设备点开链接就能看、能改，邮件里可以放可点链接。
- **成本**：0 元（免费层），但运维复杂度上一个台阶，且**与你已定的「先本地」直接冲突**。

---

## 三、结论：在你的前提下，档 2 是唯一自洽的选项

推理链很短：

- 档 3 要求上云 → 你已定「先本地」，排除（以后想上云，档 2 可无缝升级，见下）。
- 档 0 等于不做跟进 → 你明确要做跟进，排除。
- 档 1 只在电脑前可见 → 你白天不在电脑前，基本没用，排除。
- **剩下档 2**。

也就是：本地定时触发 + 邮件提醒（不带链接）+ 开机补发。

「无缝升级」的意思是：触达逻辑（`notify` 接口）、触发时机、三问内容的组装方式，在档 2 和档 3 下完全一样，变的只是「跑在哪」和「邮件里能不能放链接」。所以在档 2 上写的代码，上云时不用重写。

---

## 四、你没回应时怎么办（U2 的第三件事）

这条容易被忽略，但决定跟进会不会变成噪音：

- **第 1 周**：正常发一封。
- **连续 2 周没有任何报告更新**：第二封改变性质 —— 不再是「该学习了」，而是「这个阶段是不是要改小或者停掉」，并附上重排提案。
- **连续 4 周无更新**：自动降频为每两周一次，并在正文提示「这个计划可能已经不合适了，要不要重新看一次」。

原则：跟进的目的是**让偏离可见、并提供修正**，不是施压。一直催只会让你开始忽略它，那它就死了。

---

## 五、要你拍的一句话

**U2 定为档 2（本地定时 + 邮件提醒，不带链接，含开机补发）——同意吗？**
