# 页面深色重做模板（可复刻 playbook）

> 来源：/workbench、/new、/candidates 三页共五轮打磨沉淀（2026-09-25～26）。
> 每页重做照此走，目标：一轮到位，第二轮只修用户点名细节。

## 流程（固定七步）

1. **行为冻结清单**：枚举页面调用的全部接口与交互状态，写进任务书"一个不能变"
2. **写任务书**：`design-samples/real-roundN/brief.md`——含先读清单、行为冻结、反模式禁令、组件解剖、禁改清单、完成标准
3. **反重力执行**：CLI（`design-samples/real-roundN` 目录 + 完成标记重试循环）或用户代发 GUI
4. **查岗**：`git status` 核对改动范围（曾擅自改 HANDOFF.md）
5. **三项检查**：lint / tsc / build 零错误（agy 常漏接 props，tsc 必抓）
6. **浏览器逐交互实测**：hover/active/focus/空态/错误态/滚动，DOM 量测为准（截图管线有鬼影帧）
7. **截图对照源站** → 提交

## 风格硬标准

见 `design-samples/style-dna.md`。核心：纯白是奢侈品（用户消息胶囊/主CTA）；背景分层靠浮起不靠线框；圆角肥（容器16px、气泡胶囊）；描边白4-8%；彩色只做语义（绿完成/琥珀等待/蓝行动）；元数据 11px 低亮；留白慷慨。

## 反模式禁令（用户原话级）

- 禁止等宽卡片竖排堆叠——主次靠大小与亮度，不靠框
- 禁止卡片套卡片——卡内内容直接放卡面上
- 禁止一切内容装框——段落清单可坐背景上，用留白和 hairline 分隔
- 禁止"点击后突然展开"的稳定功能区——空态也要常驻
- 原生 `<select>` 禁用（浏览器蓝下拉）——一律用 `components/ui/hover-select.tsx`（悬停即开、140ms 宽限关、底部空间不足自动向上翻）

## 页面骨架范式（进 `app/(app)/` 路由组即得壳）

- **对话型页**（工作台/找方向）：主区（列表或输入流）+ 常驻副栏（规划对话，全高，空态常驻）；副栏占比 ≥ 主角时用 `grid-cols-[480px_1fr]` 这类定宽+弹性
- **表单型页**（新建）：居中单栏 `max-w-5xl`，区块大小交替
- **列表型页**（报告/记忆/提案，待做）：beUI Task Rows 式状态胶囊行（状态圆片+标题+元数据+徽章+chevron），主推条目用 3px 白竖条标记
- 页面根节点必须挂 `dark` 类（旧元素规则的豁免开关）

## 必踩坑清单（每条都有前科）

1. 主题文件头必须 `@import "tailwindcss"`——漏了全部工具类死
2. 旧 globals.css 在 `@layer base` 且元素规则已加 `:not(.dark *)`——新页面根必须挂 `dark`
3. effect 内禁止同步 setState（项目 lint 规则）——取数态写进 .then/.finally
4. agy 常漏接新组件的 props（isBigCard、setChattingId 两次前科）——tsc 必跑必看
5. agy 会越界改共享文件（HANDOFF.md 前科）——交活先 git status 查岗
6. 原生 select 的浏览器下拉无法样式化——见 HoverSelect
7. 内置浏览器截图有鬼影/黑帧/坏帧——以 DOM 量测（getBoundingClientRect/elementFromPoint）为准
8. 迁移页面进壳时，页根的 `flex h-screen`、`dark` 类必须跟着搬
9. loading 态只能请求落定后在 .finally 清，别在 effect 里同步置位
10. agy 交活自称"已验证"不可信——/workbench 首屏渲染坏但它自称 build 通过

## 验收清单（用户视角）

- [ ] 三项检查零错误
- [ ] 每个可交互元素：hover 有反馈、active 有下沉、focus 柔和描边
- [ ] 空态/错误态/加载态都有且体面
- [ ] 长页可滚动、底部元素不被裁切（选择器自动向上翻）
- [ ] 截图与 beui.dev/beautifului.dev 同类组件并排不露怯
- [ ] 用户"毛胚感"自检：主次分明？留白够？有没有框堆框？
